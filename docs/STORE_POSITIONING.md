# Asta Matrix — store positioning draft

Asta Matrix is an independent fantasy-football auction assistant.

The product focuses on auction operations: player calls, budgets, rosters, shared countdown, bid history, tactical coverage and Matrix recommendations. New auctions use a dataset explicitly selected by the user; the application does not automatically scrape third-party fantasy-football platforms.

Suggested public description principles:

- describe the app as an independent auction-management tool;
- use “Matrix Value” / “Valore Matrix” for proprietary recommendations;
- describe imported player lists generically;
- avoid claims of official compatibility, affiliation or sponsorship without written authorization;
- do not market imported third-party values as official data supplied by Asta Matrix.

A final store description, privacy policy, trademark review and legal review are release tasks, not runtime features.
